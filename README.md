# BRD4 Predictor API (Python 3.10)

FastAPI backend for the fixed Stage 05 250-feature BRD4 model. It predicts with ExtraTrees, CatBoost, and SVR and reports standardized 5-NN, training bounding-box, and leverage applicability-domain checks.

## Assets required

Copy the six inference assets generated by Notebook 13 into `app_assets/`. The API checks their feature order and model compatibility during startup. The selected representation is 103 configured Morgan bits, 146 Mordred Community 2D descriptors, and `phys_MolLogP`; it has no 3D features and does not impute missing values. The Morgan chirality setting is read from `app_config.json` so it matches the saved feature pipeline.

## Run locally

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Open `http://localhost:8000/docs`; check `GET /api/health`. The model assets must be present first.

## Render

Create a new Render Web Service from this folder/repository using the included `render.yaml`. The Docker image installs Python 3.10 dependencies. Keep the repository private if the model/reference assets should not be distributed. This API enables wildcard CORS without credentials so the Vercel frontend can call it directly.

## API

- `GET /api/health`
- `POST /api/predict/smiles` — JSON `{ "smiles_text": "CCO ethanol" }`, one SMILES per line.
- `POST /api/predict/file` — multipart file `.sdf` or `.mol2`.

Maximum request: 250 parsed molecules, 20 MB per structure file. Prediction results include all three model predictions, per-method AD values and an `inside_all_three` flag. CSV export is handled in the frontend.
